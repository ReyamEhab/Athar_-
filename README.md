# أَثَر | ATHAR

موقع عربي متعدد الصفحات للاستغفار والتدبر.

## الصفحات
- `index.html` — الرئيسية
- `istighfar.html` — عداد الاستغفار مع هدف قابل للتغيير
- `quran.html` — آيات قرآنية وروابط للمصحف
- `hadith.html` — أحاديث وروابط التحقق في الدرر السنية
- `journey.html` — قائمة نية يومية وملاحظات شخصية

## التشغيل
افتح `index.html` في المتصفح، أو ارفع المجلد كاملاً إلى GitHub Pages أو استضافة ثابتة. حافظ على مجلد `assets` بجانب الملفات.

## ملاحظات
- الإعدادات والعداد والملاحظات تُحفظ محلياً في المتصفح نفسه ولا يوجد خادم أو حساب مستخدم.
- يحتاج Google Fonts إلى اتصال بالإنترنت، ويمكن للموقع استخدام الخطوط البديلة عند انقطاعه.
- تحققي من نصوص الأحاديث وتخريجها من المصادر الأصلية قبل الاستخدام العام.
